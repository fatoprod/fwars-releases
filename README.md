# 🚀 FWars - Releases Oficiais

Repositório oficial de distribuição e atualizações automáticas (OTA) do jogo **FWars** para Linux e Windows.

---

## 🎮 Como Baixar e Jogar

Acesse a aba de **[Releases](https://github.com/fatoprod/fwars-releases/releases)** para baixar a versão mais recente:

* **Linux (.AppImage):** Baixe o arquivo `.AppImage`, dê permissão de execução (`chmod +x FWars_*.AppImage`) e execute com dois cliques.
* **Linux (.deb):** Instalador compatível com Ubuntu, Debian, Pop!_OS, Mint e Zorin.
* **Windows (.exe / .msi):** Instalador tradicional para Windows 10 e 11.

---

## 🔄 Atualizações Automáticas (OTA)
O **FWars** possui suporte nativo a atualizações Over-The-Air:
Ao abrir o jogo instalado no seu computador, ele verifica silenciosamente esta página e notifica você diretamente no HUD caso uma nova versão esteja disponível.
